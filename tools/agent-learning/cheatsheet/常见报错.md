# 常见报错速查（Python + 调 API）

> 每遇到一个看不懂的报错，就往这里加一条：**报错原文 + 原因 + 怎么修**。
> 这是 Python 副线最高效的学法——以报错驱动，别啃教材。

---

## IndentationError: unexpected indent
- **现象**：代码跑不起来，提示缩进错误。
- **原因**：Python 靠缩进（行首空格）区分代码块，多一个空格、混用空格和 Tab 都会报错。
- **修**：统一用 **4 个空格**缩进；PyCharm 里把 Tab 设成插入 4 空格。

## ModuleNotFoundError: No module named 'requests'
- **现象**：`import requests` 报错。
- **原因**：没装这个库。
- **修**：终端运行 `pip install requests`。其它库同理，缺啥装啥。

## NameError: name 'xxx' is not defined
- **现象**：用了没定义过的变量/函数。
- **原因**：拼错名字，或忘了赋值就用。
- **修**：检查拼写；确认这行之前已经 `xxx = ...`。

## KeyError: 'choices'
- **现象**：`data["choices"]` 报错。
- **原因**：API 返回的不是你预期的结构，多半是请求出错了（key 错、模型名错、欠费）。
- **修**：先 `print(data)` 看真实返回；多半里面有 `error` 字段告诉你原因。

## 请求失败 401 / 403
- **原因**：API Key 不对 / 没权限 / 没充值。
- **修**：检查 key 有没有多余空格；确认账号有额度。

## 请求失败 404
- **原因**：`BASE_URL` 或 `MODEL` 名字写错。
- **修**：去对应平台文档核对模型名和接口地址。

## ConnectionError / 超时
- **原因**：网络问题；或用了需要科学上网的地址（如 OpenAI 官方）。
- **修**：换国内服务（硅基流动 / 智谱）；或检查代理。
