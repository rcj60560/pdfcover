① 先过一遍「概念词汇」

新手最大的卡点就是看不懂词。先把这张表抄进 notes/00-概念词汇.md，每个花 5 分钟查懂——不用很深，知道是什么、解决什么问题就行。别等"全懂了"才开始。

概念一句话
LLM大语言模型，Agent 的"大脑"
Prompt / Token / Context提示词 / 计费单位 / 上下文窗口（模型一次能看多少字）
Function / Tool Calling让模型能"调用函数/工具"（查天气、查数据库）—— Agent 的核心
Agent Loop"思考→调用工具→看结果→再思考"的循环，Agent 就是这个循环
RAG检索增强生成，让模型读你自己的文档再回答
Embedding / 向量数据库把文字变成数字做"相似度搜索"，RAG 的底层
MemoryAgent 怎么跨对话记住事情
MCP模型上下文协议，让 Agent 接外部工具的通用标准
LangChain / LlamaIndex主流开发框架（封装了上面这些东西）

② 分阶段学习路线

主线是 Agent，Python 是"够用就行"的副线。勾选进度会自动保存（仅本浏览器）。

第 1–2 周 · 上手感

阶段 1：让概念"活"起来

  • Python 学 Python-100-Days 的 Day01–Day15（变量/分支/循环/函数/列表字典/字符串/文件读写/try-except）。够看懂 90% 报错就停下，别恋战。
  • 注册一个模型 API（国内可用 硅基流动 / 智谱，或 OpenRouter），拿到 API Key。
  • 用 Python 发第一条请求，让 LLM 回你一句话。运行 code/01-hello-llm.py。
第 3–5 周 · 核心机制

阶段 2：搞懂 Agent 怎么"动"

  • Prompt 工程：少样本、角色设定、结构化输出。
  • Function / Tool Calling：让模型决定调用哪个函数、传什么参数。
  • 手撕一个 Naive RAG：切块 → embedding → 相似度检索 → 拼 prompt。
  • 跟着 AgentGuide 的 开发岗路线 走，理解 LangChain 核心概念。
第 6–8 周 · 动手

阶段 3：从零写一个 Agent

  • 理解 Agent Loop：写一个 while 循环，让模型反复"调用工具 → 看结果 → 继续"。
  • 加上 Memory：把历史对话存起来塞进下次请求。
  • 跟着 ai-agents-from-zero 从零搭一个迷你 Agent 框架。亲手写一遍 > 看十遍。
第 9 周起 · 出作品

阶段 4：做一个完整小项目

  • 选题（任选一）：个人知识库助手 / 自动总结网页 / 命令行小助手 / RSS 摘要机器人。
  • 做完能跑，写进 README 截图发出来。有项目才有转行的资本。

④ 这个项目怎么用（本地学习 + 跑代码）

你已经在 tools/agent-learning/ 里了，目录长这样：

tools/agent-learning/
├── index.html          ← 你正在看的这个学习主页
├── dev_server.py       ← 托管本页面的本地服务器（:7000）
├── README.md           ← 学习日志：今天学了啥、卡在哪、明天干嘛
├── notes/              ← 概念笔记（markdown）
│   └── 00-概念词汇.md   ← 第一篇笔记（已建好）
├── code/               ← 跟练代码，一个文件一个知识点
│   └── 01-hello-llm.py ← 第一段：调 API 让模型说话（已建好）
└── cheatsheet/         ← 报错速查 / 常用片段
    └── 常见报错.md       ← 每遇报错就往这里加一条

💡 关键习惯：每遇到一个看不懂的报错，就往 cheatsheet/常见报错.md 加一条（报错原文 + 原因 + 怎么修）。这是 Python 副线最高效的学法——以报错驱动，而不是啃教材。

📖 笔记和报错文件都能在浏览器直接看：notes/00-概念词汇.md · cheatsheet/常见报错.md
