# 00 · 概念词汇表

> 新手第一道坎就是看不懂词。把这张表填满，每个词做到「能用自己的话讲出来」就算过关。
> 不用一次全懂，边学边回来补。每条尽量配一个最小例子或类比。

---

## LLM（大语言模型）
Agent 的"大脑"。你给它文字，它回你文字。
例子：ChatGPT、Claude、GLM、DeepSeek 都是 LLM。

## Prompt（提示词）
你写给模型的那段话。模型只看这段话决定怎么回。
小例子：`请把下面这句话翻译成英文：你好世界`

## Token
模型的计费/切分单位，大约「1 个汉字 ≈ 1–2 token，1 个英文单词 ≈ 1 token」。
context 越长、花的 token 越多、越贵。

## Context / 上下文窗口
模型一次能"看到"的最大字数上限（比如 8k / 32k / 128k token）。
超过就要截断或压缩——这是后面「上下文工程」要解决的问题。

## Function / Tool Calling（工具调用）⭐核心
让模型不只是说话，还能"决定调用哪个函数、传什么参数"。
类比：你问"今天北京天气？"→ 模型返回「请调用 get_weather(city="北京")」→ 你的代码真的去查 → 把结果喂回模型 → 它总结成自然语言。
**这一步是 Agent 和普通聊天机器人的本质区别。**

## Agent Loop（智能体循环）⭐核心
Agent 的本质就是这个循环：
```
思考 → 调用工具 → 看结果 → 再思考 → …… → 给出最终答案
```
后面阶段 3 你会亲手写一个 while 循环实现它。

## RAG（检索增强生成）
让模型"读你自己的文档"再回答，避免它瞎编。
最小流程：文档切块 → 每块算 embedding → 存进向量库 → 提问时搜最相关的几块 → 拼进 prompt。

## Embedding（向量/嵌入）
把一段文字变成一串数字（向量），语义相近的文字数字也相近。
用途：做"相似度搜索"，是 RAG 的地基。

## 向量数据库
专门存 embedding、做相似度搜索的库。常见：Chroma、FAISS、Qdrant、Milvus。

## Memory（记忆）
Agent 怎么跨对话记住事情。最简单：把历史聊天原样塞进 prompt；进阶：摘要、只存关键事实。

## MCP（模型上下文协议）
一种"通用插头标准"，让任何 Agent 都能接同一批外部工具。
你问过的 Hermes Agent 就大量用它。

## LangChain / LlamaIndex
主流开发框架，把 prompt/工具/RAG/记忆/Agent Loop 都封装好，省得自己从零写。
注意：框架会隐藏细节，**阶段 3 一定要手写一遍 Agent Loop，别只会用框架。**

---

## 学习方法提醒
- 看不懂某个词很正常，先记下来，往下学，回头就懂了。
- 优先"能跑起来"，而不是"全懂了再开始"。
