# 音频播放器 Web 应用设计文档

**日期:** 2026-07-07
**状态:** 已批准
**作者:** Claude

## 1. 概述

在 pdfcover 项目中新建一个自包含的音频播放器，部署到阿里云服务器，通过公网 IP 访问。用户在手机/pad 上打开网页，以卡片网格浏览"书"，点进某本书后看到音频列表，点击播放，同时在 pad 上用其他 app 打开对应 PDF 对照学习。

### 1.1 核心目标

- 公网访问 → 卡片网格首页（响应式，宽屏约 5 列、手机约 2 列）
- 点一本书 → 该书的音频列表（按 001、002… 顺序）
- 点一个音频 → 播放，基础音乐播放器控件（上一首/下一首、±5s、进度条、循环、倍速、音量）
- 底部常驻播放条，切换页面时音乐不中断
- 加新书 = 把文件夹传到服务器目录 + 刷新网页，零命令零脚本

### 1.2 约束条件

- **纯静态，不跑任何后台进程**（不引入 Flask/数据库/常驻服务）
- **不要访问密码**，公开访问即可
- **PDF 不归本播放器管**：用户自行在 pad/WPS 里打开对应 PDF
- 一本书 = 一个文件夹，里面是 MP3 + 规律命名（如 `001.mp3`…`020.mp3`）
- 书的来源/上传由用户手动完成（SCP 到服务器目录）

### 1.3 服务器现状（已探测）

- 公网 IP `47.108.230.162`，SSH 端口 22，Web 端口 80
- Web 服务器为 **nginx**；静态文件由 nginx 直接吐出
- 已确认静态响应头含 `Access-Control-Allow-Origin: *`（跨域 OK）与 `Accept-Ranges: bytes`（音频可拖动进度条/分段加载）
- `/script` 当前被 nginx 转发到另一个后端应用（返回 `{"code":500,...}`），**需新增 nginx location 把它改成静态目录**
- 用户有 root/sudo 权限，可编辑并 reload nginx 配置

## 2. 整体架构

```
用户浏览器（手机/pad）
    │  打开 http://47.108.230.162/script/
    ▼
nginx 托管静态文件
    ├── GET /script/             → 返回 index.html（播放器壳）
    ├── GET /script/app.js       → 播放器逻辑
    ├── GET /script/style.css    → 样式
    ├── GET /script/books/       → autoindex json → 书单（目录列表）
    ├── GET /script/books/<书>/  → autoindex json → 该书音频列表
    └── GET /script/books/<书>/001.mp3 → nginx 直接吐 MP3（支持 range）
```

**没有任何后端进程**。播放器（纯 HTML+JS+CSS）靠 nginx 的 `autoindex json` 自动发现书与音频，靠浏览器原生 `<audio>` 标签播放。

### 2.1 数据来源：nginx 自动列目录（autoindex）

- 给 `/script/books/` 开启 `autoindex on; autoindex_format json;`
- 浏览器请求目录 → nginx 返回 JSON 数组，每项形如：
  ```json
  [
    {"name":"剑桥雅思10","type":"directory","mtime":"..."},
    {"name":"新概念2","type":"directory","mtime":"..."}
  ]
  ```
- 播放器前端解析：`type==="directory"` 当作"书"，`type==="file"` 且扩展名为 `.mp3` 当作"音频"
- **加新书 = SCP 文件夹到 `books/` → 刷新网页，自动出现**，零配置

## 3. 界面设计

单页应用（SPA）风格：两个"页面"由前端 JS 切换，底部播放条常驻、跨页面不中断。

### 3.1 页面 1 · 首页（书库）—— 卡片网格

```
┌──────────────────────────────────────────────┐
│  📚 我的书库                                  │
├──────────────────────────────────────────────┤
│ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐      │
│ │ 雅  │ │ 剑  │ │ 新  │ │     │ │     │      │
│ │思德 │ │桥10 │ │概念 │ │     │ │     │      │
│ │20集 │ │16集 │ │24集 │ │     │ │     │      │
│ └─────┘ └─────┘ └─────┘ └─────┘ └─────┘      │
│  ...自动换行                                  │
└──────────────────────────────────────────────┘
```

- **响应式 CSS 网格**（`grid-template-columns: repeat(auto-fill, minmax(...))`）：宽屏≈5 列，手机≈2 列。书少就少几个卡片。
- **卡片内容**：书名首字 + 色块（当封面，不依赖图片）、书名、集数（"20集"）。点卡片进入该书详情。

### 3.2 页面 2 · 书本详情 —— 音频列表

```
┌──────────────────────────────────────────────┐
│  ← 返回    剑桥雅思10                         │
├──────────────────────────────────────────────┤
│    001                    03:42               │
│  ► 002  ◄正在播放          04:15              │
│    003                    05:01               │
│    ...                                        │
│    020                    03:58               │
└──────────────────────────────────────────────┘
```

- 一行一首：序号（取自文件名）+ 文件名 + 时长（元数据加载后显示）
- 点任意行播放；当前播放行高亮、带跳动小图标
- 顶部"← 返回"回首页

### 3.3 常驻播放条（底部）

```
┌──────────────────────────────────────────────┐
│ 001 · 剑桥雅思10        01:23 ━━━●━━━━ 04:15 │
│   [⏮][«5s][▶/⏸][5s»][⏭]   🔁  ⏩1x  🔊       │
└──────────────────────────────────────────────┘
```

- 固定底部，切页面/回首页都不中断播放
- 进度条可拖动跳转

## 4. 播放器功能

### 4.1 核心控件

| 控件 | 行为 |
|------|------|
| ▶ / ⏸ | 播放 / 暂停（点击列表行或播放按钮切换） |
| ⏮ / ⏭ | 上一首 / 下一首 |
| «5s / 5s» | 后退 / 快进 5 秒 |
| 进度条 | 可拖动跳转，显示当前时长 / 总时长 |
| 🔁 循环 | 三档状态机：关 → 单曲循环 🔂 → 整本循环 🔁 |
| ⏩ 倍速 | 0.75 / 1 / 1.25 / 1.5x 循环切换 |
| 🔊 | 音量 / 静音 |

### 4.2 自动行为

- 一首播完 → 自动下一首
- 整本播完时：循环模式为"关"则停止；"单曲循环"则重播当前；"整本循环"则回到第一首

### 4.3 不做的功能（YAGNI）

- ❌ 记忆播放进度（用户明确不需要）
- ❌ 书的封面图、自定义书名（书名 = 文件夹名）
- ❌ 搜索/收藏/用户系统
- ❌ PDF 在线阅读（用户自行在 pad/WPS 打开）

## 6. 部署

### 6.1 服务器上的布局

放到 nginx 静态根目录下（即用户上传图片能访问的那个目录体系），结构：

```
<script根目录>/
├── index.html  app.js  style.css     # 播放器（不开列目录）
└── books/                             # 音频根目录（开 JSON 列目录）
    ├── 剑桥雅思10/
    │   ├── 001.mp3
    │   ├── 002.mp3
    │   └── ...
    └── 新概念2/
        ├── 001.mp3
        └── ...
```

### 6.2 nginx 配置（示例，`nginx.conf.example` 给全量）

在现有 `server { }` 块内新增（prefix 越长越优先，会覆盖当前转发到后端的 `/script`）：

```nginx
# 播放器静态文件（不开列目录）
location /script/ {
    alias /path/to/script-root/;          # ← 改成实际目录
    autoindex off;
}

# 书库：开启 JSON 目录列表，播放器靠它自动发现
location /script/books/ {
    alias /path/to/script-root/books/;
    autoindex on;
    autoindex_format json;
}
```

改完 `nginx -t` 测试 → `nginx -s reload`。

### 6.3 加一本书的完整流程

1. 本地整理好一个文件夹（如 `剑桥雅思10/`，里面 `001.mp3`…）
2. SCP 上传到服务器 `<script根目录>/books/` 下
3. 浏览器刷新 → 新卡片自动出现

**就这一步。无脚本、无命令、无后台。**

### 6.4 本地开发/验证

`dev_server.py` 是一个极简 Python 服务器：托管静态文件，并对目录请求返回**与 nginx `autoindex json` 完全相同格式**的 JSON（`[{name, type, mtime}]`）。这样本地验证与线上一致，无需任何适配开关。

```bash
cd audioplayer
python dev_server.py 8000        # 浏览器打开 http://localhost:8000/
```

`dev_server.py` 把 `fixtures/` 当作网站根：静态文件从 `fixtures/` 取，目录列表按 nginx autoindex json 格式生成。验证整套流程后再传服务器。

## 7. 关键实现细节

### 7.1 中文路径编码

nginx `autoindex json` 的 `name` 字段是原始文件名（可能含中文）。前端拼音频 URL 时，**必须对每一段 `encodeURIComponent`**：

```js
const url = `/script/books/${encodeURIComponent(book)}/${encodeURIComponent(file)}`;
```

否则中文书名/文件名会请求失败。

### 7.2 音频排序

文件名规律命名（如 `001.mp3`）。排序策略：**按文件名开头的数字自然排序**（提取前导数字比较；无数字则按字符串）。这样 `001 < 002 < ... < 020`，也兼容未补零的 `1, 2, 10`。

### 7.3 模块拆分（便于测试与维护）

`app.js` 内把纯逻辑与 DOM/IO 分离：

- **纯函数（可单测）**：`parseListing(json)` 解析 autoindex 数组、`sortTracks(files)` 排序、`nextTrack(index, total, loopMode)` 计算下一首、`clampSeek(time, duration)` 跳转边界、`cycleSpeed(current)` 倍速档位循环、`cycleLoop(current)` 循环档位循环
- **IO/副作用**：`fetch` 目录、操作 `<audio>` 元素、渲染 DOM、绑定事件

## 8. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 拉取书单/音频列表失败（网络/nginx 未配好） | 页面提示"加载失败，请检查配置"，不白屏 |
| 某本书是空文件夹 / 无合法 mp3 | 该书卡片不显示（或列表页提示"暂无音频"） |
| 单个音频加载失败（损坏/路径问题） | 该行标红，自动跳下一首，不打断整体 |
| ±5s 跳转 | 边界 clamp：不小于 0、不超过总时长 |
| 倍速 | 仅在浏览器支持范围内（0.75–1.5x）循环 |

## 9. 测试

### 9.1 单元测试（纯逻辑）

用 node 自带测试器（`node --test`，零额外依赖），覆盖第 7.3 节的纯函数：

- `parseListing`：从 autoindex JSON 正确分出 directory/file、过滤非 mp3
- `sortTracks`：`001..020` 顺序正确；未补零 `1,2,10` 顺序正确
- `nextTrack`：各循环模式下边界（最后一首 → ？）
- `cycleLoop` / `cycleSpeed`：状态循环正确
- `clampSeek`：边界不越界

### 9.2 手动验证

用 `fixtures/books/` 假数据 + 本地 http server，验证：首页卡片 → 进书 → 播放 → 上一首/下一首/±5s/循环/倍速 → 切页不停。通过后再传服务器。
